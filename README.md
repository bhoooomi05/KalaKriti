# KalaKriti
A Digital Platform to Preserve and Promote Indian Art  and Atrisans

KalaKriti is a web-based platform built to support Indian artisans by helping them showcase, sell, and sustain traditional art forms using modern technology. The project focuses on preserving cultural heritage while creating real income opportunities for artisans.

## 📌 Why KalaKriti?

Traditional Indian handicrafts are slowly disappearing due to:

* Limited market access for artisans
* Low and unstable income
* Lack of digital exposure
* Younger generations moving away from traditional art

KalaKriti tries to bridge this gap by combining **e-commerce, learning, and community support** in one platform.


## ✨ What the Platform Offers

### 👩‍🎨 For Artisans

* Register and manage profiles
* Upload and sell handmade products
* Track orders, sales, and revenue
* Conduct workshops and skill-based sessions
* Get visibility without heavy commission cuts

### 🛍️ For Customers

* Browse authentic handcrafted products
* Filter by categories like pottery, textiles, jewelry, paintings, etc.
* Enroll in cultural workshops
* Learn about artisans and their stories
* Secure checkout and payment options

## 🧠 System Overview

* Separate interfaces for **Artisans** and **Customers**
* Centralized backend using Node.js
* Secure database access via backend only
* Clean flow from UI → Server → Database → UI

The goal was to keep the system simple, efficient, and easy to understand.

## 🚀 How to Run the Project

1. Clone the repository

   ```bash
   git clone https://github.com/your-username/kalakriti.git
   ```
2. Navigate to the project folder

   ```bash
   cd kalakriti
   ```
3. Install dependencies

   ```bash
   npm install
   ```
4. Start the server

   ```bash
   node index.js
   ```
5. Open the project in your browser
